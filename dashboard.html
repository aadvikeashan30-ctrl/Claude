What we monitor (and what we don't)

Collected (work-related only)

  • Login / logout times & active session duration
  • Idle time (no input > 5 min)
  • Application categories (work / neutral / distracting)
  • Git commits, files modified, ticket status changes
  • Meeting attendance
  • Aggregated keyboard / mouse activity counts (no content)

Never collected

  • Keystroke content, passwords, or chat messages
  • Screen recordings or screenshots
  • Personal device usage outside work apps
  • Camera / microphone
  • Location beyond work timezone

Employee rights

  • Right to view their own dashboard & reports at any time
  • Right to dispute alerts and request human review
  • Logs auto-purged after 90 days
